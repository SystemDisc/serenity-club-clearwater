# Agents

This project uses the Payload CMS skill at `.agents/skills/payload/`.
Start with `.agents/skills/payload/SKILL.md` for a quick reference, then see `.agents/skills/payload/reference/` for detailed docs.

For the club's monthly website, Google Business Profile, and Facebook analytics PDFs, use `.agents/skills/serenity-monthly-reports/SKILL.md`. It preserves the board-report layouts and prefers the previous full month, with a last-30-days-through-today fallback only where needed.
